# Personal Portfolio

A responsive portfolio website for **Mandan Sanvi Gopal**, B.E. Computer Science student.
Made for Full Stack Development, Assignment 1.

## Sections
Home, About, Education, Skills, Projects, Contact

## Features
- Project filter buttons (All / Web / Python)
- Dark and light mode
- Contact form with validation
- Back-to-top button
- Works on mobile and desktop

## Built With
HTML5, CSS3, Bootstrap 5, JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in a browser.

## Files
- `index.html` - page content
- `style.css` - styles
- `script.js` - skills, projects, theme, form validation
- `profile.jpg` - profile photo
